# 히라가나 기말 암기장

김순희 선생님 일본어 기말 대비 퀴즈·암기 앱. 정리본 PDF(13쪽)와 원본 프린트(4쪽)의 히라가나 범위 전부를 문제로 만들었다.

- `app.html` — 앱 원본 (한 파일, 외부 라이브러리 없음)
- `site/index.html` — Netlify에 올리는 완성본 (`node build.mjs`로 생성)

## Netlify에 올리기

- 가장 쉬운 방법: <https://app.netlify.com/drop> 에 `site` 폴더를 끌어다 놓기
- GitHub 연결: 이 저장소를 연결하면 `netlify.toml` 설정대로 `site` 폴더가 배포된다

진도·오답 기록은 각 브라우저의 localStorage에 저장된다.
